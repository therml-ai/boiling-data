# Boiling Data

A utility library for converting between boiling data formats

## Docs

This goals for this repo are
1. have a python object that can be used to convert simulations between different formats.
    - One just needs to define `from_<format>` and `to_<format>` functions.
2. have utilities for loading datasets, batching, setting up dataloaders, etc. 
3. utilities for computing normalization statistics.
4. Some support for doing analysis of simulations and error checking.
